# ShopEase

ShopEase is a full-stack e-commerce web application built to provide a modern and user-friendly online shopping experience.

The project includes a React-based frontend and a Node.js/Express backend with MongoDB for data management.

## Features

- User authentication and authorization
- Product browsing and product details
- Product search and category filtering
- Shopping cart
- Wishlist
- Checkout and order placement
- Admin dashboard
- Admin product management
- Product creation, editing and deletion
- REST API integration
- MongoDB database integration

## Tech Stack

### Frontend

- React
- Vite
- JavaScript
- HTML
- CSS
- React Router

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt
